# Secure Python Password Manager 🔐

A robust, Command-Line Interface (CLI) Password Manager built with Python. This project demonstrates practical applications of cybersecurity principles, including symmetric encryption and cryptographic hashing, to securely store and manage user credentials.

## 🚀 Features

* **Master Password Protection:** Authenticates users using SHA-256 hashing to ensure the main point of entry is secure.
* **Data Encryption:** Utilizes the `cryptography` library (Fernet/AES) to securely encrypt stored passwords.
* **Local Database:** Uses SQLite to store website names, usernames, and encrypted passwords efficiently.
* **Command-Line Interface (CLI):** A lightweight, fast, and secure terminal-based interface.
